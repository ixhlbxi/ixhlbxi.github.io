# ixhlbxi.github.io

Public GitHub Pages site. It exists to give personal OAuth apps the home page,
privacy policy and verified domain that Google requires before an app can be
published to **In production** (Testing-mode logins expire after 7 days).

- Home: https://ixhlbxi.github.io/
- Privacy policy: https://ixhlbxi.github.io/privacy.html
- Authorized domain: `ixhlbxi.github.io`, verified in Google Search Console with an
  HTML-file token in this repo. **Do not delete any `google*.html` file**, or the
  verification lapses.

First used for the rclone Google Drive client that uploads the family Minecraft
server's offsite backups (2026-11-09).

This repo is public. Keep hostnames, emails and anything private out of it.
